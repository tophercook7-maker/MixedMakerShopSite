## When to Fix vs Replace

Deciding whether to repair or replace a computer can be confusing. I keep it simple: ask yourself these questions.

- **Age of the machine** – If it’s more than five years old and still runs the software you need, it’s worth repairing. If it’s older than that and struggling with newer programs, it might be time for a new one.
- **Cost of parts** – If a single component (e.g., a power supply or a motherboard) costs more than half the price of a new system, it’s usually better to buy new.
- **Repair frequency** – If you’re fixing the same problem every few months, a new machine is a better investment.
- **Data safety** – If the hard drive is failing, a replacement SSD is a must. If the data is critical, I’ll back it up before replacing the drive.

I’ll give you a clear rundown of the costs and benefits before we start any work. If a repair is cheaper and the machine still runs well, I’ll go ahead. If a new machine is more cost‑effective in the long run, I’ll suggest that.
